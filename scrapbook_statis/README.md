# Vintage Scrapbook — versi HTML statis

Versi ini tidak membutuhkan Python atau Flask. Buka `index.html` untuk menguji secara lokal.

## Tambahkan foto dan lagu
- Foto: `static/images/foto-kenangan-1.jpg`
- Lagu: `static/audio/lagu.mp3`

Kalau belum ada file foto atau lagu, bagian tersebut tidak akan menampilkan media yang dimaksud.

## Publikasikan gratis
Unggah isi folder ini (bukan folder pembungkus atau ZIP) ke layanan hosting statis seperti GitHub Pages atau Cloudflare Pages. Pastikan `index.html` berada di root folder yang diterbitkan. Setelah situs mendapatkan URL HTTPS, URL itu dapat dibuat menjadi QR code.

Catatan: HTML statis dapat dibuka tanpa Flask. Beberapa HP mungkin menangani file HTML lokal berbeda; setelah diterbitkan online, akses lewat URL biasanya lebih mudah. Audio umumnya perlu diputar dengan menekan tombol play.
